حاسبة البلوت — نسخة PWA

الملفات:
index.html — الحاسبة الأصلية مع تهيئة PWA
manifest.webmanifest — معلومات التطبيق وأيقونته
sw.js — تخزين ملفات التطبيق للعمل دون إنترنت
icons/ — الأيقونات

للتجربة على الكمبيوتر: افتح مجلد المشروع في VS Code ثم شغّل عبر خادم محلي (مثل python -m http.server 8000) وادخل http://localhost:8000

للتثبيت على iPhone: ارفع جميع محتويات هذا المجلد إلى استضافة HTTPS مثل GitHub Pages، وافتح الرابط في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية. فتح index.html مباشرة كملف لا يكفي لتثبيت PWA.

ملاحظة: خطوط Google تحتاج الإنترنت لأول مرة؛ بعد ذلك يستخدم الجهاز الخطوط البديلة عند عدم الاتصال. حفظ النتائج محليًا كما في الملف الأصلي.
